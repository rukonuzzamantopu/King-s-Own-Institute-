## 📚 Subjects & Coursework

### ☕ Java — Calculator Using Swing
**Folder:** `Java/calculator-using-swing-main/`

A fully functional **desktop calculator application** built with **Java Swing** GUI framework.

**Features:**
- Graphical User Interface (GUI) built with Java Swing
- Supports basic arithmetic: Addition, Subtraction, Multiplication, Division
- Clear and reset functionality
- Responsive button layout

**Technologies Used:**
- Java SE
- Java Swing (javax.swing)
- AWT (java.awt)

**How to Run:**
```bash
# Compile
javac Calculator.java

# Run
java Calculator
```

## 🚀 Getting Started

### Prerequisites
Make sure you have the following installed:
- [Java JDK 8+](https://www.oracle.com/java/technologies/downloads/) — for Java projects
- [.NET SDK](https://dotnet.microsoft.com/download) — for C# projects
- Any modern web browser — for HTML/CSS/JS projects
- [Git](https://git-scm.com/) — to clone the repository

### Clone the Repository
```bash
git clone https://github.com/rukonuzzamantopu/King-s-Own-Institute-.git
cd King-s-Own-Institute-
```

### Run the Java Calculator
```bash
cd Java/calculator-using-swing-main
javac Calculator.java
java Calculator
```

### Open Web Projects
```bash
cd "ICT272 Web Design and Development"
# Open index.html in your browser
```
